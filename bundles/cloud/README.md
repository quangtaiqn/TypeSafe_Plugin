# Cloud bundle

This metadata is generated from the same `typesafe-ai` skill source used by the PC plugin. It describes a Streamable HTTP `/mcp` service with OAuth2 JWT/JWKS authentication; it does not contain an endpoint, app ID, secret, or deployment credential.

Before a release, regenerate the skill hash, replace the endpoint template only in a reviewed deployment ref, and attach live canary evidence. A cloud bundle is not proof that ChatGPT Web or any mobile host can load it.
